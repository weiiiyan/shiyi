# ShiYi 详细实现计划
## 一、项目背景
用户长期使用 Anki、墨墨背单词等工具，认可间隔重复算法的学习效果，但现有工具缺少**生词初次沉浸式学习**的配套能力。
本项目结合 Anki 间隔重复引擎、AI 多模态对话能力，依托「英语是运动类技能」的学习理念，打造沉浸式英语学习 Web 应用。

## 二、核心学习理念
1. 英语属于**技能型能力**，而非纯思考类知识，学习过程不插入中文翻译
2. 以**完整句子**为最小学习单元，摒弃孤立背单词的模式
3. 同一个知识点拆解为 **读、写、听、说** 四类技能卡片
4. 四类能力定义：
   - 听：声音 → 语义理解
   - 说：想法 → 口语发声
   - 读：文字 → 语义理解
   - 写：想法 → 文字输出

## 三、项目目标
搭建本地运行的 Web 应用，完整流程如下：
1. 用户选择场景子牌组（工作、日常交流、考试等）
2. 对接 Anki，拉取当前牌组当日待学卡片
3. AI 结合卡片内容、牌组场景生成沉浸式英语对话
4. 支持用户与 AI 多轮交互练习
5. AI 自动判定掌握程度，同步结果至 Anki，更新间隔重复数据

## 四、技术栈选型
| 分层 | 技术选型 | 选型理由 |
| ---- | -------- | -------- |
| 前端 | Vue 3 + Vite | 项目已完成脚手架初始化，Vue 生态成熟、组件化开发高效 |
| 后端 | Node.js + Express | 与前端同技术栈；Anki-Connect、AI 服务均基于 HTTP 接口，适配性强 |
| 语音识别 | Web Speech API (SpeechRecognition) | 浏览器原生能力，免费无额外部署，Chrome 兼容性良好 |
| 语音合成 | Web Speech API (SpeechSynthesis) | 浏览器原生 TTS，零配置、满足学习场景发音需求 |
| AI 服务 | 千问 / 豆包 等大模型 API | 支持多模型切换，由用户自主配置 API Key |
| 间隔重复引擎 | Anki + Anki-Connect（`localhost:8765`） | 算法成熟稳定，提供完整 REST 接口，便于二次对接 |

### 5.2 后端存在的必要性
1. 解决跨域：Anki-Connect 运行在本地 `8765` 端口，浏览器直接请求存在 CORS 限制，由后端统一代理转发
2. 安全防护：AI 服务的 API Key 存放于后端，避免前端明文泄露
3. 状态管理：多轮对话上下文、学习会话状态统一在服务端维护

## 六、数据模型设计
### 6.1 Anki 卡片字段设计
单条笔记对应一个最小语义单元，**一个概念拆分为 4 张不同技能类型卡片**。

| 字段名 | 字段说明 | 示例 |
| ------ | -------- | ---- |
| concept | 概念中文描述 | 我（第一人称代词） |
| word | 核心英文单词/短语 | I |
| card_type | 技能类型 | read / write / listen / speak |
| sub_deck | 所属场景子牌组 | 日常交流 / 工作英语 |
| examples | 配套例句（JSON 数组） | ["I am happy.", "I like coffee."] |
| context | 场景补充说明 | 表达自身时使用的基础代词 |

### 6.2 牌组命名规范
统一格式：`父牌组::子牌组`，后端通过前缀 `ShiYi::` 过滤目标牌组
- ShiYi::日常交流
- ShiYi::工作英语
- ShiYi::考试

## 七、核心业务流程
### 7.1 学习主循环
1. 用户选择场景子牌组
2. 后端调用 Anki-Connect，拉取该牌组**当日到期卡片**
3. 依次取出单张卡片，根据 `card_type` 生成对应学习场景
   - read：推送带目标词汇的短文，考察阅读理解
   - write：描述场景，要求用户文字输出表达
   - listen：TTS 播放音频，考察听力理解
   - speak：描述场景，要求用户口语作答
4. 接收用户文字/语音回复
5. AI 判定掌握程度（三档结果）
6. 调用 Anki-Connect 接口，更新卡片评分与间隔重复数据
7. 循环执行，直至当日卡片学习完成

### 7.2 AI Prompt 设计要点
1. 场景生成：优先使用用户 Anki 中**已掌握词汇**，控制难度
2. 作答判定：优先判断语义是否传达，弱化语法细节扣分
3. 容错机制：用户连续作答错误时，自动降低难度或允许低分跳过

## 十二、功能验证流程
1. 本地启动 Anki 客户端，并开启 Anki-Connect 插件
2. 在 Anki 中创建测试牌组（命名格式：`ShiYi::测试`），并添加测试卡片
3. 执行 `npm run dev` 启动前后端项目
4. 浏览器访问项目，选择测试牌组，进入学习流程
5. 全链路验证：AI 生成场景 → 用户作答 → AI 评分 → 后端同步数据至 Anki
6. 回到 Anki 客户端，检查卡片的间隔、复习状态是否正常更新
